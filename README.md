# 一炷（いっしゅ）

仏式のお祈りに寄り添う、線香の灯と煙のウェブアプリです。

線香の先端から立ちのぼる煙を、ノイズベースの物理パーティクルで描画しています。火の粉のような赤熱と、細い煙が空気に応じて曲がる様子を、静かな祭壇のうえで体験できます。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示されたら、線香の近くでポインタをゆっくり動かすと煙が揺れます。「消す / 点す」で着火を切り替えられます。

## 技術

- Vite + TypeScript
- Canvas 2D による煙シミュレーション（FBM / curl noise）
- CSS で再現した祭壇（岩の香立て・青磁の仏像・木の卓）

## ビルド

```bash
npm run build
npm run preview
```
